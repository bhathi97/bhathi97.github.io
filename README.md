# Portfolio Website

Personal portfolio for **Bhathiya Bandara**, built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Files

- `index.html` — page structure and content
- `styles.css` — layout, theming, and responsive design
- `script.js` — navigation, theme toggle, scroll progress, and reveal animations
- `images/` — profile photo, project screenshots, and CV PDF

## Features

- Full-bleed hero with brand-forward layout
- Light / dark theme with system preference support
- Responsive navigation and mobile contact dock
- Scroll progress and section reveal motion
